# tarea-semana-3
Git · Control de versiones · Trazabilidad · Commit · Push · GitHub
Pregunta 1:
¿Qué es Git?
Respuesta: B. Un sistema de control de versiones para registrar cambios en proyectos.

Pregunta 2:
¿Cuál es la función principal de un repositorio?
Respuesta: B. Registrar y organizar los archivos y cambios de un proyecto.

Pregunta 3:
¿Qué hace el comando git add .?
Respuesta: B. Agrega archivos al área de preparación para registrar cambios.

Pregunta 4:
¿Qué hace el comando git commit?
Respuesta: A. Guarda un registro de cambios realizados en el proyecto.

Archivo: conceptos-git.txt
Repositorio:
Es un espacio donde se guardan los archivos de un proyecto. También permite organizar y ver los cambios que se han realizado con el tiempo.
Commit:
Es como guardar una fotografía del proyecto en un momento específico. Permite saber qué cambios se hicieron y cuándo fueron realizados.
Push:
Es el proceso de enviar los cambios guardados desde nuestro computador hacia GitHub para que queden publicados en internet.

Archivo: reflexion-semana3.txt
Git es importante porque ayuda a mantener ordenados los cambios de un proyecto. Permite saber qué modificaciones se han realizado y evita perder información importante. También ayuda cuando varias personas trabajan en el mismo proyecto porque pueden compartir sus avances. Con Git se puede regresar a versiones anteriores si ocurre algún error. Estas herramientas hacen que el trabajo sea más seguro y organizado. GitHub permite guardar los proyectos y compartirlos con otras personas. Por eso es una herramienta útil para aprender y desarrollar programas.
